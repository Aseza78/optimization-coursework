# Optimisation Coursework

This repository contains two Linear Programming (LP) coursework assignments:
1. Group assignment (15%): electricity allocation for essential student activities.
2. Individual assignment (15%): LP formulation for production, workforce, advertising and crop-planning scenarios.

The separate group project (30%) will be added after its brief and completed work have been reviewed.

## Structure
- `group-assignment/README.md`
- `individual-assignment/README.md`
- `linkedin/LINKEDIN_POST.txt`

## Skills covered
- Linear Programming
- Decision variables
- Objective functions
- Constraints and non-negativity
- Mathematical modelling of resource-allocation problems

## Important
These documents summarise the submitted coursework. They do not claim that numerical optimal solutions were calculated. Original scans are not included because they contain personal and group-member information. Obtain permission before publicly sharing identifiable group work.
